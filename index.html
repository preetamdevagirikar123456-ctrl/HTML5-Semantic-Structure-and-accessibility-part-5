Accessibility

This website demonstrates several accessibility techniques recommended for modern websites.


  • Semantic HTML5 elements are used throughout the website.
  • Navigation can be accessed using the keyboard.
  • Form controls have associated labels.
  • Visible keyboard focus indicators are provided.
  • A skip-to-content link is provided.
  • ARIA labels are used where appropriate.
  • The website supports reduced-motion preferences.
